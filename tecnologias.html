Tecnologias que fazem parte da Computação

A Ciência da Computação utiliza diversas tecnologias para criar softwares, analisar informações e desenvolver soluções inovadoras.

Por que conhecer tecnologias?

As tecnologias são ferramentas utilizadas pelos profissionais de computação para transformar ideias em soluções reais.

Cada tecnologia possui uma finalidade diferente. Algumas são usadas para desenvolvimento de sistemas, outras para análise de dados, infraestrutura, segurança e inteligência artificial.

Linguagens de programação

Python

Uma linguagem conhecida pela simplicidade e muito utilizada em automação, análise de dados, inteligência artificial e desenvolvimento.

Java

Linguagem bastante utilizada no desenvolvimento de sistemas corporativos, aplicações Android e grandes plataformas.

C e C++

Linguagens próximas ao funcionamento do computador, utilizadas em sistemas operacionais, jogos e aplicações de alto desempenho.

JavaScript

Uma das principais tecnologias da web, permitindo criar páginas interativas e aplicações modernas.

Desenvolvimento Web

HTML

Responsável pela estrutura das páginas da internet.

CSS

Define aparência, organização visual e responsividade dos sites.

Frameworks

Ferramentas que aceleram o desenvolvimento, como React, Angular e Vue.

Banco de Dados

SQL

Linguagem utilizada para consultar, organizar e manipular informações armazenadas.

MySQL

Sistema de gerenciamento de banco de dados muito utilizado em aplicações web.

PostgreSQL

Banco de dados robusto utilizado em aplicações de diferentes tamanhos.

Ferramentas importantes

Git

Ferramenta de controle de versão usada para acompanhar alterações em projetos.

GitHub

Plataforma utilizada para armazenar projetos, colaborar e construir um portfólio.

Linux

Sistema operacional muito utilizado em servidores, desenvolvimento e infraestrutura.

Tecnologias em crescimento

Inteligência Artificial

Criação de sistemas capazes de analisar dados, aprender padrões e auxiliar decisões.

Computação em Nuvem

Uso de servidores online para armazenar dados e executar aplicações.

Cibersegurança

Proteção de sistemas, redes e informações contra ameaças digitais.
