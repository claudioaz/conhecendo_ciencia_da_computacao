Sobre o projeto Computação Descomplicada

Uma iniciativa educativa criada para aproximar pessoas do universo da Ciência da Computação.

Sobre a iniciativa

O Computação Descomplicada foi desenvolvido com o objetivo de apresentar a área de Ciência da Computação de uma maneira simples, acessível e educativa.

Muitas pessoas possuem interesse por tecnologia, mas não sabem exatamente como funciona uma graduação, quais conhecimentos são necessários ou quais caminhos profissionais existem na área.

Este projeto busca reduzir essa barreira, oferecendo informações organizadas sobre cursos, tecnologias, carreiras e possibilidades de aprendizado.

Objetivos do projeto

Informar

Apresentar conceitos de computação de forma clara para pessoas que estão conhecendo a área.

Incentivar estudantes

Mostrar oportunidades acadêmicas e profissionais existentes na tecnologia.

Compartilhar conhecimento

Facilitar o acesso a conteúdos educativos gratuitos sobre computação.

Para quem é este site?

Estudantes do ensino médio

Pessoas que estão escolhendo uma carreira e querem entender melhor a área de tecnologia.

Iniciantes em programação

Quem deseja começar seus estudos e conhecer os primeiros passos.

Interessados em tecnologia

Qualquer pessoa curiosa sobre como computadores e softwares transformam o mundo.

Tecnologias utilizadas

HTML5

Utilizado para criar a estrutura das páginas do projeto.

CSS3

Responsável pelo design, layout e responsividade.

JavaScript

Utilizado para criar interações como animações e o quiz educativo.

Projeto de extensão universitária

Este site representa uma iniciativa de compartilhamento de conhecimento, utilizando a tecnologia como ferramenta para educação e divulgação científica.
